
# Personal Notes Manager

## Description
A Python project that allows users to add, view, search, and delete personal notes. Notes are stored in a text file for future use.

## Features
- Add new notes
- View saved notes
- Search notes by keyword
- Delete selected notes
- Store notes permanently in `notes.txt`
- Simple menu-driven interface

## Technologies Used
- Python 3
- File Handling

## Concepts Learned
- Lists and strings
- Loops and conditional statements
- File reading and writing
- Searching with keywords
- Exception handling
- `enumerate()` and `lower()`

## Future Improvements
- Edit existing notes
- Add dates and times
- Organize notes into categories
