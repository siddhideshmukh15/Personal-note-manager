
# Personal Notes Manager

## Description
Personal Notes Manager is a simple Python project that
allows users to create, view, and save personal notes in a text file.

## Features
- Add new notes.
- View saved notes.
- Store notes in `notes.txt`.
- Keep notes saved after closing the program.
- Simple menu-driven interface.

## Technologies Used
- Python 3
- File Handling

## Concepts Learned
- Variables and strings
- User input and output
- `while` loops
- Conditional statements
- File handling (`open()`, `read()`, `write()`)
- Exception handling (`try-except`)

## Future Improvements
- Delete individual notes.
- Search for notes.
- Edit existing notes.
- Add dates and times to notes.
